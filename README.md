## 🖥️ COMPLETE SETUP GUIDE (Step-by-Step for Beginners)

### STEP A: Install Python (if not already installed)

1. Go to **https://www.python.org/downloads/**
2. Download **Python 3.10 or higher**
3. **IMPORTANT**: During installation, check the box ✅ **"Add Python to PATH"**
4. Click "Install Now"
5. To verify, open Command Prompt (Windows) or Terminal (Mac) and type:
   ```
   python --version
   ```
   You should see something like: `Python 3.12.x`

---

### STEP B: Install Visual Studio Code

1. Go to **https://code.visualstudio.com/**
2. Download and install VS Code
3. Open VS Code
4. Install these **extensions** (click the Extensions icon on the left sidebar):
   - **Python** (by Microsoft) — ESSENTIAL
   - **Pylance** (by Microsoft) — for better code suggestions
   - **SQLite Viewer** (by Florian Klampfer) — to view your database

---

### STEP C: Set Up the Project

1. **Download this entire `uber_eats_project` folder** to your computer
   (e.g., save it to `C:\Users\YourName\Documents\uber_eats_project`)

2. **Place your raw data files** in the `data/raw/` folder:
   - `Uber_Eats_data.csv`
   - `orders.json`

3. **Open the project in VS Code**:
   - Open VS Code
   - Go to **File → Open Folder**
   - Select the `uber_eats_project` folder
   - Click "Select Folder"

---

### STEP D: Create a Virtual Environment

A virtual environment keeps your project's packages separate from other projects.

1. In VS Code, open the **Terminal** (press `` Ctrl + ` `` or go to **Terminal → New Terminal**)

2. Run these commands ONE BY ONE:

   **On Windows:**
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

   **On Mac/Linux:**
   ```
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. You should see `(venv)` at the beginning of your terminal line — this means the virtual environment is active.

4. **Tell VS Code to use this environment:**
   - Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on Mac)
   - Type: **"Python: Select Interpreter"**
   - Choose the one that shows `./venv/...` or `venv`

---

### STEP E: Run the Scripts

**Run Step 1 (Data Cleaning):**
```
python scripts/step1_data_cleaning.py
```
This will create cleaned CSV files in `data/cleaned/`

**Run Step 2 (Database Setup) — coming next:**
```
python scripts/step2_database_setup.py
```
This will create the SQLite database in `database/`

**Run Step 3 (Streamlit App) — coming next:**
```
streamlit run app/streamlit_app.py
```
This will open the web app in your browser!

## 📌 Common Issues & Fixes

| Problem | Solution |
|---------|----------|
| `python` not recognized | Reinstall Python with "Add to PATH" checked |
| `pip` not recognized | Use `python -m pip install` instead |
| `ModuleNotFoundError` | Make sure `(venv)` is active, then run `pip install -r requirements.txt` |
| Streamlit not opening | Try `python -m streamlit run app/streamlit_app.py` |
| VS Code not finding Python | Press `Ctrl+Shift+P` → "Python: Select Interpreter" → choose `venv` |
